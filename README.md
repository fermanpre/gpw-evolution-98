# GPW Evolution '98: community proposals / propuestas de la comunidad

Public list of ideas for GPW Evolution '98, a Grand Prix World 1998 mod, with a form to send new ones. Unofficial fan project.

Lista pública de ideas para GPW Evolution '98, un mod de Grand Prix World 1998, con un formulario para enviar otras nuevas. Proyecto de aficionados, sin carácter oficial.

- `index.html`: the list (English by default, Spanish with the selector) / la lista.
- `propose.html`: the form / el formulario.
- `mod.html`: download page of version 0.1 and general notes / página de descarga de la versión 0.1 y notas generales.
- `descargas/`: README, credits and DxWnd profile of the pack (the zip itself is on the Releases page) / README, créditos y perfil de DxWnd del paquete (el zip está en Releases).
- `generador/`: the script and the data that build both pages (`lista.json`) / el script y los datos que generan las dos páginas.
- `datos/publico.csv`: sanitized answers (names only if the person chose to appear) / respuestas saneadas (nombres solo si la persona eligió figurar).

The pages are regenerated every day by a GitHub Action from the published sanitized CSV.
